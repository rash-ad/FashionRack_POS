# Fashion Rack POS - Clothing Website

A **simple and responsive clothing website** built using **Tailwind CSS**. This project is a **Point of Sale (POS) system** style web interface for browsing, selecting, and managing clothing products online. It’s designed to be clean, user-friendly, and mobile-responsive.

---

## Features

- Fully **responsive design** for desktop, tablet, and mobile screens.
- **Tailwind CSS** for easy and modern styling.
- **Product catalog** showcasing clothing items.
- **Add to cart** functionality (front-end simulation).
- **Clean and intuitive UI/UX**.
- Simple navigation and layout.

---

## Tech Stack

- **HTML5**
- **Tailwind CSS**
- **JavaScript** (for basic interactions, optional)
- **Responsive design principles**
